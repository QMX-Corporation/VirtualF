1. Fork, Clone, See and Modify.

  * Fork the repository (QMX-Corporation/VirtualF.git)
  * git clone https://github.com/QMX-Corporation/VirtualF.git to clone 
  * Entry in a File or create:

2. Open the Pull Request.

      git push origin main 
      # Entry in your Fork (Navigator, Sites) and 
      # click in "Contributte" and, after, click in 
      # "Open a Pull Request".
